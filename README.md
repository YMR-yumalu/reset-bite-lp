# RESET BITE — LPポートフォリオ作品

**架空のサプリメント商品**を題材に制作したランディングページです。
実在する商品ではなく、記載の成分・効能表現はデザイン学習用の架空のものです。

- 制作：鈴木 夢（Yume Suzuki）
- 技術：HTML / CSS（フレームワーク・JavaScript不使用）
- デザイン：Figma で設計 → コーディング
- 想定：スマートフォン（幅393px基準の縦長LP）

## 構成
1. ヒーロー（グリーングラデーション）
2. 共感チェックリスト（7項目）
3. コンセプト（食後ケア × 腸内ケア × 脂肪対策）
4. 厳選6成分
5. こんな方におすすめ
6. LINE CTA
